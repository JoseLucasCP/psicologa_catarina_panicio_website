## Website - Psicóloga Catarina Panício

Este website foi desenvolvio para a Psicóloga Catarina Panício como porta inicial de sua carreira com o objetivo de apresentar sua trajetória profissional, divulgar seus serviços e facilitar o contato com potenciais pacientes e empresas.

## Objetivo

Ao mesmo tempo em que aprendo, pratico e começo a desenvolver minhas skills como desenvolvedor, estou elaborando um site institucional simples, responsivo e acessível.
